Marigold

A private postpartum recovery companion.

Problem
A recovery app that gives daily guidance should not send sensitive health check-ins to a cloud model, and should never let a model improvise medical advice.
Approach
An open-weight model (Qwen2.5 3B Instruct, Apache-2.0) served by Ollama on localhost writes a short daily plan from a fixed catalog: movement, meals, comfort practices and a plain "call a clinician" instruction when the check-in says so. The app refuses ids and phrases the model is not allowed to use.
Outcome
Data stays in browser storage and there is no cloud model. It works offline once the model is downloaded, and falls back to a catalog-built plan if Ollama is down.
  • Next.js
  • TypeScript
  • Ollama
  • Qwen2.5

Agentic engineering workflow

How I run my development.

Problem
AI-written code is fast but unreviewed, and fake dependency PRs now carry malware, such as the "fake font" family.
Approach
A multi-agent setup: a manager model breaks work into tasks for specialised subagents (coder, reviewer, tester, scanner, verifier, runner) on smaller models, and can delegate across providers for independent second reviews. A custom supply-chain guard (malware scanner, git hooks, CI workflow and force-push alerts) blocks that malware family.
Outcome
Every push is gated on tests plus an AI code review. This is private tooling, so there is no public link.
  • Claude Code subagents
  • Git hooks
  • CI
  • Code review gates

Playbright

A Chrome extension for streaming video.

Problem
Dark scrims over streaming video black out the picture, and per-site rules break whenever a site changes.
Approach
Manifest V3 and dependency-free. It detects and fades dark scrims over video without hard-coded site rules, with per-site settings, presets, a keyboard shortcut and a click-to-hide picker. Built with the agentic workflow above.
Outcome
It stays idle on pages without video.

  • Manifest V3
